# PROYECTOS
Proyectos destacables en los que he trabajado.
Los archivos ".RData" y "video games sale.csv" corresponde al manejo de análisis de datos mediante lenguaje R, en el archivo .RData contiene la limpieza del dataset mencionado y las predicciones realizadas en ella. 
Los archivos "agencia_de_autos.sql" y "interfaz.php" corresponden a la base de datos de la agencia ficticia de autos, se ejecuta en un entorno HTML con conexión a SQL, en ella se puede consultar los autos disponibles mediante la busqueda avanzada de tipo de auto, marca, modelo, rango de precio, color, etc. Así como agregar o eliminar autos, clientes, proveedores y empleados, en el caso de los empleados se le asigna su puesto, salario y a que area corresponde.
