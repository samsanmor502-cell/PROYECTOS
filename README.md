# Portafolio de Proyectos Universitarios

Este repositorio contiene proyectos destacados desarrollados durante la Ingeniería en Ciencias de la Computación, enfocados en análisis de datos y desarrollo de bases de datos.

## 1. Análisis de Datos: Ventas de Videojuegos
**Tecnologías:** R, RStudio
*   **Objetivo:** Limpieza y análisis exploratorio (EDA) de un dataset de ventas de videojuegos.
*   **Desarrollo:** Se aplicó la metodología KDD para el preprocesamiento de la información. El script en R contiene la implementación de modelos predictivos para identificar patrones en las ventas.
*   *Archivos:* `video games sale.csv` (Datos originales) y script de R.

## 2. Sistema Web y Base de Datos para Agencia de Autos
**Tecnologías:** SQL, PHP, HTML
*   **Objetivo:** Diseño e implementación de una base de datos relacional para la gestión operativa de una agencia automotriz ficticia.
*   **Desarrollo:** Creación de una interfaz web en HTML/PHP conectada a SQL. Permite:
    *   Búsqueda avanzada de vehículos (tipo, marca, modelo, rango de precio, color).
    *   Gestión (altas/bajas) de inventario de autos, clientes y proveedores.
    *   Administración de empleados, asignación de puestos, salarios y áreas.
*   *Archivos:* `agencia_de_autos.sql` (Estructura de la BD) e `interfaz.php` (Lógica web).
